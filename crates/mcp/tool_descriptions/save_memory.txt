Purpose: Persist a long-term memory entry that survives across sessions and observation cleanup. Searchable via `query_memory`.

When: Recording a stable, reusable, verified conclusion — a non-obvious pattern, an architectural decision, an error signature with its fix, a session summary, a user preference. Do NOT save raw logs, transcripts, every tool call, temporary guesses, or large documentation.

Prereq: None. (Note: `resolve_debug_session` writes a richer SessionSummary memory automatically; prefer it for debug-session resolutions.)

Args:
  - content: required string. The memory body, plain text.
  - kind: optional string. pattern | decision | error_signature | session_summary | user_flagged. Default user_flagged.
  - tags: optional list. Free-form retrieval tags.
  - source_observations: optional list of int. Observation ids that informed this memory.
  - project_slug: optional string. Scope for retrieval.
  - session_id: optional string. Producing session.
  - confidence: optional float [0.0, 1.0]. Default 1.0.

Returns:
  result: {id}.

Errors:
  - memory_store_unavailable: persistence not configured.

Next: query_memory to verify retrievability; forget_memory(confirm=true) only if you need to delete.
