Read a deliber8 inbox — the envelopes (messages, control signals, lifecycle notifications) queued for a specific agent address. Read-only; does not transition envelope state.

Use this to:
- See what is pending for a specialist before issuing more work.
- Confirm a control envelope was delivered after sending one.
- Investigate why a specialist appears stalled (queued backlog, failed deliveries, expired envelopes).
- Audit recent activity for a specific address.

Parameters:
- address: string. Required, non-empty. Inbox address to query, e.g. "agent:my-specialist".
- statuses: optional list. Filter by envelope status. Allowed values: queued, delivered, read, failed, expired, cancelled. Empty list or omitted returns all statuses.
- limit: optional integer. Maximum envelopes returned. Default 20, capped at 500.

Returns: { address, total, queued, delivered, read, failed, expired, cancelled, envelopes: [...] }. Counts reflect the returned slice, not the entire inbox — increase `limit` if you need totals across a large inbox.
