Search long-term memories. Filters compose with AND semantics; results are ordered by creation time (newest first).

Use this to:
- Check whether a relevant pattern or prior decision exists before acting.
- Retrieve a specific session summary or error signature by tag.
- Audit recent memories scoped to one project.

Parameters:
- text: optional string. Substring search across memory content.
- kinds: optional list of strings. Filter to specific kinds: pattern, decision, error_signature, session_summary, user_flagged.
- tags: optional list of strings. All listed tags must be present on each result.
- project_slug: optional string. Scope to one project.
- limit: optional integer. Maximum number of results. Default 20.

Returns: { total: <int>, memories: [ { id, content, kind, tags, project_slug, created_at, ... } ] }. Empty result list (`memories: []`) is the canonical response when nothing matches — not an error.

Read-only. Searches the legacy `memory` table; for tier-aware queries see `query_memory_tier`.
