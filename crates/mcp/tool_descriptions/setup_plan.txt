Purpose: Compute the action plan `setup_apply` would execute, without writing anything. Reports planned source registration, provider config, hook installation, setup-state diffs.

When: Previewing a setup change before mutating files; diffing against `setup_status` to understand exactly what will change.

Prereq: None.

Args:
  - cwd: optional string. Project working directory. Defaults to the daemon's cwd.

Returns:
  result: {status: {...same shape as setup_status.result}, actions: [{kind, target, detail, mutating}]}.
  Empty actions array means nothing needs to change.

Errors: none expected.

Next: setup_apply(yes=true) to execute; setup_status to confirm post-apply.
