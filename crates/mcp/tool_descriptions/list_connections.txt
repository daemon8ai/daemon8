List all active data source connections feeding observations into the daemon. Includes connected applications, the browser, and any device transports.

Use this to:
- Confirm the daemon is receiving telemetry from the source you expect.
- Diagnose missing observations: a source not in this list is not connected.
- Inspect the current browser endpoint (after `connect_browser`).

Parameters: none.

Returns: { browser: { state, endpoint, ... }, applications: [ { name, state, ... } ], devices: [ { serial, platform, state, ... } ] }. State is one of: connected, connecting, reconnecting, disconnected. Empty arrays when no sources are wired.
