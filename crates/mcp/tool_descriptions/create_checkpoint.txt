Mark the current position in the observation stream. Returns a checkpoint id that can be passed as `since_checkpoint` to `query_observations` so subsequent queries return only observations recorded after this call.

Use this to:
- Bookmark "now" before making a change: create_checkpoint → run the change → query_observations with `since_checkpoint`.
- Tighten subsequent queries to a known window without juggling timestamps.

Parameters: none.

Returns: { "checkpoint": <int> }. The checkpoint is monotonic and stable across the daemon's lifetime.

Read-only with respect to data — observations are not affected. The checkpoint is a label, not a snapshot.
