Purpose: Inspect the active lens (if any) and the ring buffer behind it. Read-only.

When: Verifying the lens filter matches expectations, checking buffer depth before `query_observations` (deep buffer means the next query will return many matches), or confirming the lens survived a long session.

Prereq: None.

Args: none.

Returns:
  result: {active, filter, buffered, capacity, cursor}.
  cursor = highest seq processed; buffered = current ring count.

Errors: none expected.

Next: query_observations to drain the buffer; clear_lens when done.
