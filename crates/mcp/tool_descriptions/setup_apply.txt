Purpose: Apply the plan from `setup_plan`. Writes global config, registers runtime sources, installs hooks, writes provider config files. Idempotent — re-running on an unchanged tree is a no-op.

When: Wiring a new project into the daemon (first time), re-applying after editing `.daemon8.toml`, repairing drift reported by `setup_status`.

Prereq: None.

Args:
  - yes: required boolean. MUST be true to confirm the mutation. The MCP gate refuses any other value.
  - cwd: optional string. Project working directory.
  - providers: optional string. Comma-separated providers to configure (e.g. "claude,cursor,windsurf"). Omit to skip provider writes.
  - install_hooks: optional string. Hook scope: local | shared | global.
  - force_hooks: optional boolean. Replace stale daemon8 hook entries.

Returns:
  result: {status (post-apply state), actions: [...executed...]}.

Errors:
  - missing_yes: yes was absent or false. hint: pass yes=true to confirm.

Next: setup_status to confirm; hooks_list to inspect installed hooks; for previews use setup_plan.
