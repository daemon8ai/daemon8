List the deliber8 agent roster — cards registered in the daemon's card store. Defaults to alive agents; pass an explicit `statuses` list to include other lifecycle states.

Use this to:
- See which agents are currently running and idle vs working.
- Audit a slug before sending a control envelope, verifying the target exists.
- Find retired or failed agents when investigating past activity.
- Filter to a specific kind (e.g. only bookkeepers, only specialists).

Parameters:
- kinds: optional list. Filter by agent kind: specialist, steward, bookkeeper. Empty list or omitted returns all kinds. Kind filter runs in-process AFTER the store-side limit, so combine narrow `kinds` with a generous `limit` (or filter at the caller) for reliable results.
- statuses: optional list. Filter by agent status. Allowed values: created, starting, alive, busy, paused, degraded, stopping, failed, retired. Empty list or omitted defaults to ["alive"].
- project_ref: optional string. Scope to one project's roster (passed through to the store filter).
- team_ref: optional string. Scope to one team's roster (passed through to the store filter).
- limit: optional integer. Maximum cards returned. Default 50, capped at 500.

Returns: { total, agents: [ { id, slug, kind, status, address, display_name, started_at, last_seen_at, heartbeat_interval_ms, project_refs, team_refs, ... } ] }.
