Report the current daemon8 setup state for one project: which sources are registered, which providers are wired up, whether daemon8 is installed as a system service, and whether the global config is healthy. Read-only — does not write config, hook files, provider files, or runtime data.

Use this to:
- Determine whether `daemon8 setup apply` has been run for the current working directory.
- Audit which sources, providers, and hooks the daemon thinks are configured.
- Confirm a fix landed before re-running `setup_apply`.

Parameters:
- cwd: optional string. Project working directory. Defaults to the daemon's current directory.

Returns: { project: { slug, root, config_present, source_intents, ... }, global_setup_applied, providers, hooks, ... }. Same shape as `setup_plan` minus the `actions` list.
